# Hero direction prototype

Throwaway local comparison for the Nothing But Nails Hero direction question. It is not part of the client Demo and must not be packaged or deployed.

From `/Volumes/EXTERNAL/海外落地页/client_uk_nothing_but_nails`, run:

```sh
python3 -m http.server 4288 --bind 127.0.0.1
```

Then open one of:

- `http://127.0.0.1:4288/prototype_hero_directions_20260901/?direction=cover`
- `http://127.0.0.1:4288/prototype_hero_directions_20260901/?direction=poster`
- `http://127.0.0.1:4288/prototype_hero_directions_20260901/?direction=ledger`
