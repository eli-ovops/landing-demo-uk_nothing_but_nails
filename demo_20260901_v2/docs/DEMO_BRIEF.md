# Nothing But Nails — Local concept Demo brief

## Audience and first-screen job

The visitor is an Arundel-area person who has reached a booking/profile surface and wants to decide, quickly, whether this is the right kind of nail appointment. In five seconds, the first screen must identify **Nothing But Nails**, **Arundel**, nail artistry/treatment, and a credible onward path to the current booking page.

## Commercial task

The current Fresha page has appointments, reviews and work photos, but it is primarily an appointment marketplace profile. The one-page concept should give the business a self-contained, shareable identity and a clearer journey: visual recognition → services → appointment confidence → Fresha booking.

## Page hierarchy and section jobs

1. **Hero:** identity + nail-art visual proof + one booking route.
2. **The edit:** translate four verified services into a fast, non-catalogue decision structure.
3. **The appointment ritual:** clarify that hands and feet treatments are available, without inventing technique, prices or promises.
4. **Arundel / booking:** give location and the existing Fresha handoff.
5. **Closing:** repeat one specific, factual next action.

## CTA and non-scope

Single action: `Book on Fresha`, always linking to the existing public booking page. No form, payment, calendar, price list, availability statement, newsletter, login, customer data collection, deployment, outreach or production claim.

## Implementation statement

This is a static commercial landing page, not a dashboard, workbench, catalogue clone or booking platform. The page uses four distinct customer-authorised work images from the named Fresha merchant profile, each source-ledgered and limited to this local Concept Demo. It does not identify customers, staff or premises, or make unverified treatment-result claims.
